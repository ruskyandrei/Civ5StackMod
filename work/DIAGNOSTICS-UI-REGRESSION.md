# Built-in diagnostics controls: source checkpoint

The Game Lua bindings expose the native diagnostics service through GetStackingDiagnosticsLevel, SetStackingDiagnosticsLevel and GetStackingDiagnosticsStatus. The setter accepts only numeric values equal to0/1/2 and returns the resulting level. Registration/declarations and argument position1 match CvLuaStaticInstance. The wrapper issues no network/gameplay order or RNG call. Core logging/default/reset behavior is owned by CvStackingDiagnostics and is not implemented by these UI changes.

The already registered StackPanel add-in contributes one entry to EUI's existing Additional Information dropdown. Its independent, initially hidden panel offers Off/Summary/Verbose, current native status/path/error, and the XML-default reopening notice. Access does not depend on selection, stack size or UIStackEnabled. The entry uses art="" to avoid an extra floating EUI icon. Opening it cancels an active stack-target selection before showing the panel, but issues no unit orders. Existing roster layout and movement code are otherwise retained. Closing/city-screen/player changes hide it; shutdown removes its menu-gather hook. Missing native diagnostics APIs hide the entry for compatibility with older DLLs.

Validation: work/test-diagnostics-ui.py executes the complete current StackPanel Lua in Lua5.1 with deterministic UI/native-service stubs:37 checks pass for default-off/no mutation on load, no-selection access, levels, current-state/error/path display, dynamic layout, reopening default notice, external state readback, Escape/close/city-screen/player change, missing APIs and hook removal. XML parsing and source wrapper declarations/registration/exact-level guard checks pass. Exact hashes are in work/diagnostics-ui-regression/result.json.

The existing work/test-stack-ui.py regression also passes its roster, capacity/HP/moves, selected row, preview reasons, protector/fog warning, frozen membership, result counts, visible-only badges, combat summary, cargo, late-arrival and stationary-dirty refresh checks.
